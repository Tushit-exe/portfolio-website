# DESIGN.md - Tushit Audi Portfolio Design System

## Aesthetic Direction
- **Editorial Brutalism**: Dark luxury mode (`#0a0a0a`, `#0d1117`) paired with crisp light cream sections (`#FAF9F6`), bold display typography (`Syne`), clean labels (`Inter`), and monospace code (`JetBrains Mono`).

## Color Tokens
- **Background Dark**: `#0a0a0a` / `#0d1117`
- **Background Light**: `#FAF9F6` / `#F5F4F0`
- **Primary Text**: `#ffffff` / `#080808`
- **Muted Text**: `#a1a1aa` / `#71717a` / `#666666`
- **Accent Highlighting**: `#38bdf8` (electric cyan), `#4ade80` (vibrant green), `#fb923c` (orange)

## Anti-Patterns Avoided
- No generic, plain system fonts or washed-out gray-on-gray low contrast.
- No clunky nested cards or dated bounce/elastic motion curves.
- Strict layout alignment, responsive grid edge symmetry, and 60fps hardware-accelerated animations via GSAP & ScrollTrigger.
